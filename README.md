Классический тетрис, перенесённый в третье измерение! Управляйте падающими трёхмерными фигурами, заполняйте слои и набирайте очки.

🧠 Концепция
Tetris 3D — это модификация культовой игры, где фигуры падают в трёхмерном пространстве. Игрок управляет перемещением и вращением фигуры по трём осям, стремясь заполнить горизонтальные слои. Особенности:

✅ Трёхмерное поле — сетка размером 4×4×4 (настраивается).

✅ Объёмные фигуры — 7 классических тетрамино, адаптированных для 3D (состоят из 4 кубиков).

✅ Вращение по трём осям — фигуру можно поворачивать вокруг X, Y и Z.

✅ Управление — перемещение по горизонтали (A/D), глубине (W/S), вращение (Q/E/R), мгновенное падение (Space).

✅ Система слоёв — при заполнении слоя (4×4) он очищается, и игрок получает очки.

✅ Визуализация — консольное отображение всех слоёв сверху для удобного обзора.

✅ Увеличение сложности — скорость падения растёт с каждым уровнем.

🚀 Как запустить
Все версии являются консольными приложениями. Управление осуществляется клавишами:

A/D — перемещение по оси X (влево/вправо)

W/S — перемещение по оси Y (вперёд/назад)

Q/E — вращение вокруг оси Z (влево/вправо)

R — вращение вокруг оси X (опционально)

Space — мгновенное падение

Esc — выход

Запуск на разных языках
bash
# Python
pip install keyboard  # для неблокирующего ввода (опционально)
python tetris3d.py

# C++
g++ -std=c++17 tetris3d.cpp -o tetris3d -lncurses  # или без ncurses, с простым getch
./tetris3d

# Java
javac Tetris3D.java && java Tetris3D

# C#
dotnet run

# Go
go run tetris3d.go

# Rust
cargo run

# JavaScript (Node.js)
node tetris3d.js
